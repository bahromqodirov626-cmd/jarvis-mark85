# JARVIS — O'zbek Tilidagi Shaxsiy Aqlli Yordamchi

Ushbu loyiha Google Gemini AI va Microsoft Edge Neural TTS ovozlari asosida ishlaydigan zamonaviy, tiniq va sof o'zbek tilidagi ovozli yordamchi tizimidir.

## Xususiyatlari:
1. **Sof O'zbek Tili**: Begona so'zlarsiz, adabiy va ravon o'zbek tilida muloqot qiladi.
2. **Tabiiy Ovoz (Edge-TTS)**: Robotdek emas, haqiqiy inson talaffuziga yaqin `Sardor` (erkak) va `Madina` (ayol) ovozlari.
3. **Cyberpunk / Sci-Fi Interfeys**: Stark Industries uslubidagi aylanuvchi Arc Reactor, ovoz to'lqinlari, yozish va mikrofondan gapirish imkoniyati.
4. **Veb orqali API Kalit kiritish**: Sozlamalar menyusi orqali brauzerning o'zida API kalitni oson kiritish va saqlash mumkin.

## Ishga tushirish:
1. `start.bat` faylini ikki marta bosing (yoki terminalda `python app.py`).
2. Brauzeringizda `http://127.0.0.1:5000` manzilini oching.
3. Sozlamalar (⚙️) bo'limidan Google Gemini API kalitingizni kiriting va JARVIS bilan suhbatlashing!
